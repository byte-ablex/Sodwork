# Sodwork

A simple personal webpage built with HTML, CSS, and JavaScript.

## Project overview
This project is a small website with:
- a home section
- a search section
- an about section
- a contact section
- a search box that opens a selected search engine in a new tab

## Files
- `sodwork.html` – page structure and content
- `sodwork.css` – styling for the website
- `sodwork.js` – search functionality and button interactions

## Features
- Navigation links for different sections of the page
- Search input with Google, DuckDuckGo, and Bing options
- Responsive and simple styling
- Personal profile and contact information
